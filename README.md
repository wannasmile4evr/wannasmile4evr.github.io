### 🌐 Overview

WannaSmile4Evr is a browser-based project built around a customizable dashboard and a collection of interactive pages. It combines personalization, navigation, and connected services into one evolving web experience.

### ✨ Features

- **Dashboard** — Centralized navigation, search, and user controls.
- **Personalization** — Themes, profile pictures, banners, and customization settings.
- **Page collection** — A growing selection of pages and browser-based experiences.
- **Communication** — A direct-message interface and related community features.
- **Daily features** — Quotes, daily picks, shortcuts, and interactive widgets.
- **Access system** — Ticket-based access and user-specific settings.
- **Performance** — Asset loading optimizations and optional local data caching.

### 🛠️ Tech Stack

- HTML5, CSS3, and JavaScript
- Google Apps Script and Google Sheets integrations
- GitHub Pages hosting
- Shoelace web components
- Font Awesome icons

### 🚀 Getting Started

Visit the live website to explore the project:

**[Open WannaSmile4Evr →](https://wannasmile4evr.github.io/)**

To explore or work on the source code, clone the repository:

```bash
git clone https://github.com/wannasmile4evr/wannasmile4evr.github.io.git
cd wannasmile4evr.github.io
```

Open `index.html` in VS Code and use a local development server to test changes. Some features depend on external services and may require their configured endpoints and access permissions.

### 📁 Repository Structure

| Path | Purpose |
|---|---|
| `assets/` | Images, icons, and other static assets |
| `documentation/` | Project documentation |
| `system/` | Core stylesheets, scripts, and supporting resources |
| `workflows/` | Workflow-related project files |
| `.github/workflows/` | GitHub Actions workflows |
| `index.html` | Main website entry point |
| `data.gs` | Google Apps Script integration |
| `version.json` | Version and update metadata |

### 📌 Project Status

WannaSmile4Evr is an evolving project. Features, pages, and integrations may change as development continues.
